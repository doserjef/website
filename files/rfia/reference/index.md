# Package index

## Estimation functions

- [`area()`](area.md) : Estimate forest land area from FIADB

&nbsp;

- [`areaChange()`](areaChange.md) : Estimate land area change from the
  FIADB

&nbsp;

- [`biomass()`](biomass.md) : Estimate tree biomass and carbon stocks
  from the FIADB

&nbsp;

- [`carbon()`](carbon.md) : Estimate carbon stocks by IPCC forest carbon
  pools from the FIADB

&nbsp;

- [`customPSE()`](customPSE.md) : Post-stratified estimator for custom
  variables in FIA Data

&nbsp;

- [`diversity()`](diversity.md) : Estimate diversity from FIADB

&nbsp;

- [`dwm()`](dwm.md) : Estimate volume, biomass, and carbon stocks of
  down woody material (fuels) from FIADB

&nbsp;

- [`fsi()`](fsi.md) : Estimate the Forest Stability Index from the FIADB

&nbsp;

- [`growMort()`](growMort.md) : Estimate growth, recruitment, mortality,
  and harvest rates from FIADB

&nbsp;

- [`invasive()`](invasive.md) : Estimate invasive species coverage from
  FIADB

&nbsp;

- [`seedling()`](seedling.md) : Estimate seedling abundance per acre
  from FIADB

&nbsp;

- [`standStruct()`](standStruct.md) : Estimate forest structural stage
  distribution from FIADB

&nbsp;

- [`tpa()`](tpa.md) : Estimate trees per acre and basal area per acre
  from FIADB

&nbsp;

- [`vegStruct()`](vegStruct.md) : Estimate vegation cover by canopy
  layer from FIADB

&nbsp;

- [`vitalRates()`](vitalRates.md) : Estimate tree growth rates from
  FIADB

&nbsp;

- [`volume()`](volume.md) : Estimate merchantable tree volume from the
  FIADB

## Download, read, and write FIA data

- [`getFIA()`](getFIA.md) : Download FIA Data and Load into R

&nbsp;

- [`readFIA()`](readFIA.md) : Load FIA database into R environment from
  local directory

&nbsp;

- [`writeFIA()`](writeFIA.md) : Write FIA tables to local directory

## Space-time queries, plots, and helper functions

- [`clipFIA()`](clipFIA.md) : Spatial and temporal queries for FIADB

&nbsp;

- [`intersectFIA()`](intersectFIA.md) : Intersect FIA data with spatial
  polygons

&nbsp;

- [`plotFIA()`](plotFIA.md) : Static and animated plots of FIA summaries

&nbsp;

- [`makeClasses()`](makeClasses.md) : Convert numeric variables to class
  intervals (factor)

## Design information

- [`findEVALID()`](findEVALID.md) : Find EVALIDs used in the FIADB

&nbsp;

- [`getDesignInfo()`](getDesignInfo.md) : Extract design features for
  FIA inventories

## Data

- [`fiaRI`](fiaRI.md) : FIADB for Rhode Island 2013 - 2018

&nbsp;

- [`countiesRI`](countiesRI.md) : County boundaries of Rhode Island
