# County boundaries of Rhode Island

`sf` data frame representing county boundaries in the state of Rhode
Island. Specify `countiesRI` as the `polys` argument with `fiaRI` as the
`db` argument in any `rFIA` function to produce estimates summarized by
these areal units within the state of Rhode Island. NOTE: the
`countiesRI` object was updated in v1.1.0 to be of class `sf`.

## Usage

``` r
data("countiesRI")
```

## Format

Formal class sf

## Examples

``` r
data(countiesRI)
```
