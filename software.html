Software

R packages for Bayesian spatial statistics, occupancy and abundance modeling, and forest inventory analysis.

spOccupancy

spOccupancy fits single-species, multi-species, and integrated spatial occupancy models using Markov chain Monte Carlo (MCMC).

Docs GitHub CRAN

spAbundance

spAbundance fits univariate (i.e., single-species) and multivariate (i.e., multi-species) spatial N-mixture models, hierarchical distance sampling models, and generalized linear mixed models using Markov chain Monte Carlo (MCMC).

Docs GitHub CRAN

rFIA

The goal of rFIA is to increase the accessibility and use of the USFS Forest Inventory and Analysis (FIA) Database by providing a user-friendly, open source platform to easily query and analyze FIA data.

Docs GitHub CRAN
