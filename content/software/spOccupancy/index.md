See the [spOccupancy website](https://www.jeffdoser.com/files/spoccupancy-web/) for the full package documentation and associated tutorials.

spOccupancy fits single-species, multi-species, and integrated spatial occupancy models using Markov chain Monte Carlo (MCMC). Models are fit using P&oacute;lya-Gamma data augmentation. Spatial models are fit using either Gaussian processes or Nearest Neighbor Gaussian Processes (NNGP) for large spatial datasets. The package provides functionality for data integration of multiple single-species occupancy data sets using a joint likelihood framework. For multi-species models, spOccupancy provides functions to account for residual species correlations in a joint species distribution model framework while accounting for imperfect detection. `spOccupancy` also provides functions for multi-season (i.e., spatio-temporal) occupancy models.
