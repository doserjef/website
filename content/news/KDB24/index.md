A new paper led by Ken Kellner at Michigan State University was recently published in Ecology. We assessed the analytic reproducibility of nearly 500 papers from 2018-2022, finding that only 7% of papers had R code that ran without any errors. We provide some practical recommendations for both authors and journals to consider to improve the reproducibility of code in ecological research. See the [paper here](https://esajournals.onlinelibrary.wiley.com/doi/epdf/10.1002/ecy.4475) for more details.
