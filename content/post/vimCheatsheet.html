Here I provide some useful commands for using vi.

Commenting out a Block of Code

  1. Go to first line you want to comment: press ctrl v. This puts you in the Visual Block mode.
  2. Use the arrow key and select until the last line.
  3. Press Shift i, which puts the editor in Insert mode and then press #. This will add a hash to the first line
  4. Press Esc.

Copying text to the global clipboard

  1. "+y
  2. "+p
  3. To copy the entire file into the + register, gg"+yG

Moving around

  1. Move cursor to top of screen: gg
  2. Move cursor to bottom: shift + g
  3. Move cursot to end of current line: g_
  4. Move to the beginning of line: 0
